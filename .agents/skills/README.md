# ApexOS Agent Skills

This directory is the proposed canonical location for project-authored Agent Skills.

- Skills must follow the Agent Skills format and be validated before use.
- Do not add third-party skills here until their source, license, version, scripts/hooks and compatibility have been reviewed and approved.
- Keep skills narrow and task-triggered. Put stable project rules in `docs/AGENT_RULES.md`, not duplicated into every skill.
- Host-specific discovery paths must be tested; this directory alone does not guarantee Claude Code, Codex and GitHub Copilot will all load the skills.
- See [Skill Ecosystem Research](../../docs/agent-system/SKILL_ECOSYSTEM_RESEARCH.md) and [Curated Skill Architecture](../../docs/agent-system/SKILL_ARCHITECTURE.md).
